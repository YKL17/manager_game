# 金牌经纪人 1996 · Golden Agent

一个可以在手机和电脑浏览器运行的 **独立、可修改的篮球经纪人与球队经营模拟游戏**。

> **重要：这不是虎扑原游戏源码的搬运，也不是 1:1 复刻。**
> 项目是根据公开链接标题中提到的「经纪人」和「购买球队当老板」方向创作的第一版独立游戏原型。原始链接没有对外返回可核验的游戏机制、页面内容、脚本资产，所以没有宣称与原游戏的细节完全一致。球队、球员、UI 及模拟规则均为独立制作，使用虚构数据。

参考游戏：https://activity-static.hupu.com/shaper/published/app_4762e3ab42/index.html?night=0

## 已完成的功能

- **经纪人经营**：签约客户、经纪名额与签约费用、每周合同佣金、合同加薪谈判和冷却期。
- **球队老板**：12 支可收购的虚构俱乐部，拥有球队后能签约自由球员、提升场馆、青训和商业设施。
- **联赛模拟**：每周所有球队各赛两场，每赛季 26 周。展示联盟排行榜、我的球队赛果与冠军奖金。
- **经济系统**：现金、收购成本、球员签字费、工资支出、门票、赞助收入与随机经营事件。
- **存档**：浏览器自动保存到 `localStorage`，支持导出 / 导入 JSON 和重置。
- **可编辑**：所有数值、赛季时间、球队名称、球员基础数据和经营逻辑都在项目代码中。
- 无后端、无需付费 API、无需登录；所有核心资源可离线运行（系统字体回退可用）。

## 本地运行

需要 Node.js 18+。

```bash
npm start
```

打开 http://localhost:5173 。不需要 `npm install`；项目没有任何第三方 npm 依赖。

运行基本测试：

```bash
npm test
```

也可以使用任何静态 HTTP 服务器托管项目根目录。由于浏览器的模块安全限制，不建议直接双击 `index.html` 使用 `file://` 打开。

## 游戏调整指南

| 想修改 | 文件 / 变量 |
| --- | --- |
| 初始资金、赛季长度、最高客户数 | `src/engine.js` 中的 `CONFIG` |
| 球队名称、价格、球迷基础 | `src/data.js` 中的 `CLUBS` |
| 球员的姓名、能力、潜力、合同 | `src/data.js` 中的 `PLAYERS` 生成器 |
| 购买、签约、谈判、训练、每周结算 | `src/engine.js` 中的 `reduceGame()` |
| 联赛评分、比赛模拟 | `src/engine.js` 中的 `clubStrength()` / `simulateScore()` |
| 游戏页面、导航与按钮 | `src/app.js` |
| 视觉风格与移动端响应式布局 | `styles.css` |

存档格式为 `SAVE_FORMAT = 1`。如果以后变更规则，建议新增存档版本转换，以免让已有玩家的存档失效。
