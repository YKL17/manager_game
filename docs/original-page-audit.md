1. 先审查真实游戏页面的内嵌脚本，区分经营/赛事/存档规则与虎扑专属平台代码。
2. 核查初始化是否强制要求虎扑账号、认证令牌、Colorbox AI SDK 或平台请求。
3. 对可离线实现的 UI 和游戏机制，采用独立实现并编写回归测试。
4. 对云存档、排行榜、登录等依赖平台的功能，另外设计本地存档或自有后端。
5. 不直接将未经许可的第三方页面源码、专有素材或 SDK 重新发布到公开仓库。
